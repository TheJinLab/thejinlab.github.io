Software

GetOrganelle

Organelle genome assembly from short-read genome-skimming data, combining read recruitment with assembly graph interpretation.

Source code↗2020 paper↗

Traversome

A graph-based likelihood framework for genomic variant and relative-frequency inference from assembly graphs and long-read paths. A manuscript describing the method is in preparation.

Source code↗Research→

PhyloShape

We are developing a Python toolkit for 3D morphology, including ancestral shape reconstruction in a phylogenetic framework.

Source code↗Research→

Whorlet

A workflow for automated batch photogrammetric reconstruction from turntable image sets, with quality assessment and model review. Release in prep.
